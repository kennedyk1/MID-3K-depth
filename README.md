# MID-3K — Depth modality

[Main dataset repository](https://github.com/kennedyk1/MID-3K) · [Dataset website](https://kennedyk1.github.io/MID-3K/) · [Metadata](https://github.com/kennedyk1/MID-3K/blob/main/metainfo.csv)

This repository contains depth images derived from the Ouster LiDAR point clouds and their person annotations for the MID-3K Multimodal ISR Dataset.

## Repository contents

| Path | Format | Count | Description |
| --- | --- | ---: | --- |
| `images/` | PNG, 640 × 512 | 3,083 | LiDAR-derived depth images |
| `labels/` | TXT, YOLO `xywhn` | 3,083 | RGB-derived person annotations |

Dataset size: approximately **977 MB**. The repository contains **10,824** person annotations.

## LiDAR source and projection

| Field | Value |
| --- | --- |
| LiDAR | Ouster OS1-64-U |
| Vertical resolution | 64 channels |
| Horizontal resolution | 2,048 points per scan |
| Output resolution | 640 × 512 |

The depth images are generated by projecting LiDAR points onto the RGB image plane. Use the [COLOR camera from LiDAR calibration](https://github.com/kennedyk1/MID-3K/blob/main/calibration/color_lidar/calibration.yaml) with the raw scans in [MID-3K-pcd](https://github.com/kennedyk1/MID-3K-pcd).

Each label line uses normalized YOLO format:

```text
class x_center y_center width height
```
